# FLO.W Core 反馈

欢迎来到 FLO.W Core 的反馈角落。

用的时候哪里别扭，或一直想要某个能力，都可以写在这里。其他人也能看见，碰上同一件事，在那条下面补一句或点个表情就好。

产品在 [21obsidian.com](https://21obsidian.com)。这里收的是使用里的感受和想法，源码在别处维护。

## 怎么写

1. 先在 [Issues](https://github.com/eryidebiji/flow-core-issues/issues) 里看看，有没有人说过类似的事
2. 有的话，在那条下面补上你的情况就好
3. 没有的话，点 New issue，选「碰到问题」或「一个想法」

账号、订单、设备这些和个人相关的事，走网站更合适，那里能对上你的账号。安全方面的事也请私下告诉我，避免公开后被误用。

写的时候尽量不要带上笔记原文、库的路径、订单号或验证码。截图里如果有这些，遮一下就行。

每条我都会读到。
