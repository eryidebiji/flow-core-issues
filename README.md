# FLO.W Core 反馈

这是 [FLO.W Core](https://21obsidian.com) 的公开反馈仓，**不是源码仓库**。

FLO.W Core 是闭源商业软件。这个仓库只用来收集缺陷和功能建议，方便大家先搜索、再补充、用表情投票。源码不在这里，也不会接受代码贡献。

## 怎么反馈

1. 先在 [Issues](https://github.com/eryidebiji/flow-core-issues/issues) 里搜索，看有没有类似单子。
2. 有的话，点个表情或补一句你的情况，不必再开一张。
3. 没有的话，点 New issue，选「缺陷」或「功能建议」。不相关的问题请拆开写。

## 不要发到这里

这些内容请走 [21obsidian.com](https://21obsidian.com) 的网站客服，不要发到公开 Issue：

- 登录、设备、订单、退款、权益开通
- 安全漏洞
- 任何 Vault 路径、笔记正文、订单号、验证码或账号隐私

截图前请先遮住个人内容。

## 说明

公开 Issue 只表示我们收到了。单子多的时候，很多会先收集、不承诺处理时间。
