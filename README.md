# FLO.W Core 反馈

这个仓库用来收集 FLO.W Core 的缺陷和功能建议。产品在 [21obsidian.com](https://21obsidian.com)，源码不在这个仓库。

## 怎么写

1. 先在 [Issues](https://github.com/eryidebiji/flow-core-issues/issues) 里搜索有没有相同内容
2. 有的话，在原条目下补充或点表情
3. 没有的话，点 New issue，选「缺陷」或「功能建议」

账号、订单、设备相关事项走网站。安全问题私下联系，不要发在公开讨论里。

公开内容里不要写笔记原文、库路径、订单号或验证码。截图里如有这些，先遮住。
